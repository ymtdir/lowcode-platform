# 認証機能

## 概要

Supabase Authを使用したメール/パスワード認証を実装。

## 実装済み機能

- [x] ユーザー登録（メール/パスワード）
- [x] ログイン・ログアウト
- [x] セッション管理
- [x] 認証状態の保護（ミドルウェア）
- [x] ユーザーロール設定（Admin/Member）
- [x] 認証フォームのコンポーネント化
- [x] メール確認フロー（`/confirm`）
- [x] Prismaへのユーザー情報同期

## ユーザーロール

### Admin

- すべての操作が可能
- ユーザー管理、グループ管理
- システム設定の変更

### Member

- 所属グループの権限に応じた操作
- 自身のプロフィール編集

## 認証フロー

### サインアップ

1. ユーザーがメール/パスワードを入力
2. Supabase Authでアカウント作成
3. 確認メール送信
4. ユーザーがメール内リンクをクリック
5. `/confirm` でトークン検証
6. Prismaにユーザー情報を同期
7. ダッシュボードにリダイレクト

### ログイン

1. ユーザーがメール/パスワードを入力
2. Supabase Authで認証
3. セッション作成
4. ダッシュボードにリダイレクト

### ログアウト

1. Supabase Authでセッション削除
2. ログイン画面にリダイレクト

## ミドルウェア

認証が必要なルート（`/(protected)/*`）へのアクセスを制御。
未認証ユーザーは`/login`にリダイレクト。
